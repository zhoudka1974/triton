### 溢出检查（Triton 自动生成）

Triton 对所有涉及 `i32` 的整数乘法、加法等运算自动生成**溢出安全检测代码**，在 IR 层面体现为：

```
原始 Python: pid * 128              (两个 i32 相乘可能溢出)
    ↓
Triton 自动生成:
  %pid_64 = arith.extsi %pid : i32 to i64            // 提升到 i64 空间
  %c128_64 = arith.constant 128 : i64
  %off_64 = arith.muli %pid_64, %c128_64 : i64       // 在 i64 中计算

  // 检查 i64 结果是否在 i32 范围内
  %max = arith.constant 2147483647 : i64
  %min = arith.constant -2147483648 : i64
  %le = arith.cmpi sle, %off_64, %max : i64           // ≤ MAX_INT?
  %ge = arith.cmpi sge, %off_64, %min : i64           // ≥ MIN_INT?
  %ok = arith.andi %le, %ge : i1                       // 范围有效?

  // 在 i32 空间执行实际运算（%ok 为 false 则结果未定义）
  %off_i32 = arith.muli %pid, %c128 : i32
```

**实际效果**：每个 `pid * 128` 这样的整数运算，Triton 会额外生成约 **8-12 条 MLIR 指令**（2 条 extsi + 1 条 muli + 2 条 constant + 2 条 cmpi + 1 条 andi），这些指令在统计中占了 `extsi`(175 次)、`icmpSLE`(84 次)、`icmpSGE`(84 次)、`andi`(86 次) 的高频计数——它们大部分来自溢出检查而非内核的实际业务逻辑。

## TTIR 阶段包含的 MLIR Dialect

`ttir`（Triton Tensor IR）不是单一 MLIR dialect，而是编译管道中的一个**阶段名称**，包含多个 dialect：

| MLIR Dialect | 命名空间 | 包含操作 | 来源 |
|-------------|---------|---------|------|
| **arith** | `arith.*` | `addi`, `addf`, `subi`, `subf`, `muli`, `mulf`, `divsi`, `divf`, `remsi`, `extsi`, `trunci`, `cmpi`, `cmpf`, `andi`, `ori`, `xori`, `shli`, `ashri`, `shrui`, `select`, `bitcast`, `constant`, `minnumf`, `maxnumf` | 上游 MLIR |
| **tt** (Triton) | `tt.*` | `splat`, `addptr`, `load`, `store`, `get_program_id`, `make_range`, `expand_dims`, `broadcast`, `dot`, `reduce`, `scan`, `atomic_rmw`, `trans`, `reshape`, `func`, `call`, `return` | **Triton 自定义** |
| **scf** | `scf.*` | `for`, `while`, `condition`, `yield`, `execute_region` | 上游 MLIR |
| **math** | `math.*` | `exp`, `sqrt`, `absf`, `absi` | 上游 MLIR |
| **cf** | `cf.*` | `br`, `cond_br` (控制流转换后) | 上游 MLIR |
| **ub** | `ub.*` | `poison` (未定义行为标记) | 上游 MLIR |

**关系图**：

```
ttir 阶段 = arith (算术/比较) 
         + tt (Triton 专有: load/store/dot/splat/...) 
         + scf (控制流) 
         + math (数学函数)
         + cf + ub (辅助)
```

**关键**：通用算术和控制流 Triton 直接复用上游 MLIR 标准 dialect，只定义自己独有的操作（`tt.*`）。

## 五、行号映射示例

以 `vec_add` 内核为例，展示 Python 源码每行 → AST 节点 → 完整 TTIR MLIR 的对应。

### 函数定义

```python
@triton.jit
def vec_add(x_ptr, y_ptr, out_ptr, N: tl.constexpr):
```

```mlir
// tt.func: 定义一个公开 GPU 内核函数
// 参数: %x_ptr 类型为 !tt.ptr<f32> (指向 f32 的 GPU 指针)
//       %y_ptr 同上
//       %out_ptr 同上
//       %N 类型为 i32 (32位整数)
// 无返回值 (GPU 内核函数通过 store 输出结果)
// public: 此函数是导出的入口点
// noinline = false: 允许内联
tt.func public @vec_add(%x_ptr: !tt.ptr<f32>, %y_ptr: !tt.ptr<f32>,
                        %out_ptr: !tt.ptr<f32>, %N: i32)
    attributes {noinline = false} {
```

### 第 3 行: `pid = tl.program_id(0)`

```python
pid = tl.program_id(0)
```

```mlir
// tt.get_program_id: 获取当前程序的 block ID (program ID)
// x: axis=0 (x 维度), 返回 i32 标量
// 结果赋值给 SSA 值 %pid
%pid = tt.get_program_id x : i32
```

### 第 4 行: `off = pid * 128 + tl.arange(0, 128)`

Triton 对此行做了**溢出安全检查**（防止 i32 乘法/加法溢出），生成了大量额外的 MLIR 指令。

```python
off = pid * 128 + tl.arange(0, 128)
```

```mlir
// 步骤 1: 常量定义
%c128 = arith.constant 128 : i32                        // 常量 128 (i32)

// 步骤 2: 溢出检查前的类型提升 (i32 → i64)
%pid_i64 = arith.extsi %pid : i32 to i64                // pid i32→i64 (符号扩展)
%c128_i64 = arith.extsi %c128 : i32 to i64               // 128 i32→i64

// 步骤 3: 在 i64 空间计算 pid*128（避免 i32 溢出）
%off_64 = arith.muli %pid_i64, %c128_i64 : i64           // pid * 128 (i64)

// 步骤 4: 检查 i64 结果是否在 i32 范围内
%max = arith.constant 2147483647 : i64                   // i32 最大值
%min = arith.constant -2147483648 : i64                  // i32 最小值
%le = arith.cmpi sle, %off_64, %max : i64               // off_64 ≤ MAX_INT?
%ge = arith.cmpi sge, %off_64, %min : i64               // off_64 ≥ MIN_INT?
%ok = arith.andi %le, %ge : i1                           // 范围检查通过?

// 步骤 5: 在 i32 空间执行实际运算
%off_i32 = arith.muli %pid, %c128 : i32                  // pid * 128 (i32)

// 步骤 6: tl.arange(0, 128) → 生成 0..127 的 1D 张量
%range = tt.make_range {end = 128 : i32, start = 0 : i32} : tensor<128xi32>

// 步骤 7: 将 i32 标量 %off_i32 广播为 tensor<128xi32>
%off_splat = tt.splat %off_i32 : i32 -> tensor<128xi32>

// 步骤 8: 第二次溢出检查（scalar + tensor 维度）
// 将标量结果和 range 都提升到 i64 做加法
%off_splat_64 = arith.extsi %off_splat : tensor<128xi32> to tensor<128xi64>
%range_64 = arith.extsi %range : tensor<128xi32> to tensor<128xi64>
%off_64_2 = arith.addi %off_splat_64, %range_64 : tensor<128xi64>

// 第二次溢出检查 (tensor 版本)
%max_d = arith.constant dense<2147483647> : tensor<128xi64>
%min_d = arith.constant dense<-2147483648> : tensor<128xi64>
%le_2 = arith.cmpi sle, %off_64_2, %max_d : tensor<128xi64>
%ge_2 = arith.cmpi sge, %off_64_2, %min_d : tensor<128xi64>
%ok_2 = arith.andi %le_2, %ge_2 : tensor<128xi1>

// 步骤 9: 最终 i32 结果
%off = arith.addi %off_splat, %range : tensor<128xi32>
```

### 7.4 Triton Dialect (tt) 操作

```mlir
// ── tt.splat (标量→张量广播) ──
%t = tt.splat %s : i32 -> tensor<128xi32>                // 1D
%t = tt.splat %s : f32 -> tensor<64x32xf32>              // 2D

// 1D: ptr[128] + off[128] → ptr[128]

%v = tt.load %ptr : tensor<128x!tt.ptr<f32>>
// 1D mask: tl.load(ptr, mask=m)
%v = tt.load %ptr, %mask : tensor<128x!tt.ptr<f32>>
// 2D: tl.load(2d_ptr) → tensor<64x32xf32>
// 2D: tl.load(2d_ptr) → tensor<16x8x4xf32>  // 3D
%v = tt.load %ptr : tensor<64x32x!tt.ptr<f32>>
// 2D mask:
%v = tt.load %ptr, %mask : tensor<64x32x!tt.ptr<f32>>
// 3D:
%v = tt.load %ptr : tensor<16x8x4x!tt.ptr<f32>>

// ── tt.store (存储) ──
// 1D: tl.store(ptr, val)
tt.store %ptr, %val : tensor<128x!tt.ptr<f32>>
// 1D mask: tl.store(ptr, val, mask=m)
tt.store %ptr, %val, %mask : tensor<128x!tt.ptr<f32>>
// 2D:
tt.store %ptr, %val : tensor<64x32x!tt.ptr<f32>>
// 3D:
tt.store %ptr, %val : tensor<16x8x4x!tt.ptr<f32>>

// ── tt.get_program_id ──
%pid = tt.get_program_id x : i32                         // 标量 (block ID)
// 注: program_id 始终是标量，需要 tt.splat 广播到张量

// ── tt.make_range (tl.arange) ──
// 始终生成 1D 张量，通过 expand_dims 升维
%r = tt.make_range {end = 128 : i32, start = 0 : i32} : tensor<128xi32>

// ── tt.expand_dims ([:, None] 升维) ──
// 1D → 2D: [128] → [128,1]
%e = tt.expand_dims %in {axis = 1 : i32} : tensor<128xf32> -> tensor<128x1xf32>
// 1D → 2D: [128] → [1,128]
%e = tt.expand_dims %in {axis = 0 : i32} : tensor<128xf32> -> tensor<1x128xf32>
// 2D → 3D: [64,32] → [64,32,1]
%e = tt.expand_dims %in {axis = 2 : i32} : tensor<64x32xf32> -> tensor<64x32x1xf32>
%e = tt.expand_dims %in {axis = 2 : i32} : tensor<16x8x4xf32> -> tensor<16x8x4x1xf32>  // 3D
// 1D → 3D: [16] → [16,1,1] (通过两次 expand_dims)
%e1 = tt.expand_dims %x {axis = 1 : i32} : tensor<16xf32> -> tensor<16x1xf32>
%e2 = tt.expand_dims %e1 {axis = 2 : i32} : tensor<16x1xf32> -> tensor<16x1x1xf32>

// ── tt.broadcast (显式广播) ──
// 2D → 2D: [64,1] → [64,32]
%b = tt.broadcast %in : tensor<64x1xf32> -> tensor<64x32xf32>
%b = tt.broadcast %in : tensor<64x1xf32> -> tensor<16x8x4xf32>  // 3D
// 1D → 2D: [128] → [64,128] (沿 axis=0 广播)
%b = tt.broadcast %in : tensor<128xf32> -> tensor<64x128xf32>

// ── tt.dot (矩阵乘法) ──
// 2D matmul: [M,K] × [K,N] → [M,N]
// a: tensor<16x16xf16>, b: tensor<16x16xf16>, acc: tensor<16x16xf32>
%d = tt.dot %a, %b, %acc : tensor<16x16xf16> * tensor<16x16xf16> -> tensor<16x16xf32>
// 不带累加器:
%d = tt.dot %a, %b : tensor<16x16xf16> * tensor<16x16xf16> -> tensor<16x16xf32>

// ── tt.reduce (归约) ──
// 1D归约: [128] → f32 (axis=0)
%r = "tt.reduce"(%input) <{axis = 0 : i32}> ({
  ^bb0(%a: f32, %b: f32):
    %s = arith.addf %a, %b : f32
    tt.reduce.return %s : f32
}) : (tensor<128xf32>) -> f32

// 2D归约(axis=1): [64,32] → [64] (沿列求和)
```

### 7.8 多维张量指针构建模式

以 2D load `tl.load(x_ptr + off_m[:, None] * N + off_n[None, :])` 为例的完整翻译：

```mlir
// 步骤 1: 构建行索引 [M] 和列索引 [N]
%row = tt.make_range {start=0, end=M} : tensor<Mxi32>
%col = tt.make_range {start=0, end=N} : tensor<Nxi32>

// 步骤 2: 升维 [M] → [M,1], [N] → [1,N]
%row_2d = tt.expand_dims %row {axis=1} : tensor<Mxf32> -> tensor<Mx1xf32>
%col_2d = tt.expand_dims %col {axis=0} : tensor<Nxf32> -> tensor<1xNxf32>

// 步骤 3: 计算线性偏移 [M,1] * N + [1,N] → [M,N]
%row_off = arith.muli %row_2d, %N : tensor<Mx1xi32>
%off = arith.addi %row_off, %col_2d : tensor<MxNxi32>   // [M,N] 偏移量

// 步骤 4: 生成基指针张量 [M][N] = splat(base_ptr)
%base = tt.splat %x_ptr : !tt.ptr<f32> -> tensor<MxNx!tt.ptr<f32>>

// 步骤 5: 指针偏移 [M][N] + [M][N] → [M][N]
%ptr = tt.addptr %base, %off : tensor<MxNx!tt.ptr<f32>>, tensor<MxNxi32>

// 步骤 6: 加载 [M][N]
%val = tt.load %ptr : tensor<MxNx!tt.ptr<f32>>
```
