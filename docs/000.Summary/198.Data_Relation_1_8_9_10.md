## 共享数据关系表

### 说明
- 「加载」= pybind11 绑定或类定义通过 import 加载
- 「实例化」= 创建类实例（局部变量，不跨阶段传递）
- 「定义」= 定义在类中作为方法
- 「注册」= 注册为延迟回调
- 「赋值」= 函数/类引用赋值给实例属性
- 「调用」= 调用函数/方法
- 「读/写」= 读写数据
- 「创建」= 首次创建该数据
- 「传递」= 通过参数传递
- 「返回」= 函数返回值

## 关键数据传递路径

### 从 101 到 110 的长线数据

```
101: import triton ────────────── 加载 driver, backends, JITFunction, compile,
                                  ASTSource, CompiledKernel, ir, passes, llvm
       │
102: @triton.jit ──────────────── JITFunction.__init__() → device_caches
       │
103: kernel run ──────────────── create_binder() → target, backend, binder
       │                           binder(*args) → options, specialization
       │                           kernel_cache 查/写
       │
104: _do_compile() ──────────── ASTSource(self, ...) → self.compile(src, ...)
       │
105: compile() ───────────────── make_backend(target), ir.load_dialects()
       │                           src.make_ir() → module (mlir::ModuleOp)
       │                           backend.add_stages(stages, ...)
       │
       │    ┌────┬────┬────┬────┬────┐
       │    │106 │107 │108 │109 │110 │
       │    │ttir│ttg │llir│ptx │cubin│
       │    │    │    │    │    │    │
       │    │ module (mlir)       │ str │ bytes│
       │    │ metadata 贯穿全部 5 stage      │
       │    │ options: num_warps, num_stages  │
       │    │ capability: 89, 90              │
       │    └────┴────┴────┴────┴────┘
       │
       └─→ CompiledKernel(src, metadata_group, hash)
```

### 22~26 号共享数据的完整生命周期

```
options (CUDAOptions):
  103: _pack_args() 创建 ← 来自 binder(*args)
  104: 传递给 compile()
  105: backend.parse_options() 解析
  106→110: 各 stage 读取 (num_warps, num_stages, enable_fp_fusion 等)

metadata (dict):
  105: compile() 创建 ← 填充 hash, target, options, triton_version
  106: make_ttir() → 可能写入
  107: make_ttgir() → 写入 tensordesc_meta
  108: make_llir() → 写入 num_warps, shared, tmem_size
  109: make_ptx() → 写入 name (内核函数名)
  110: make_cubin() → 只读，不写入

capability (int):
  106: NVIDIA make_ttir() 从 options.arch 解析
  107→110: 逐 stage 传递使用

backend (BaseBackend 实例):
  102: create_binder() 通过 make_backend() 创建
  103: 从 device_caches 读取
  105: compile() 用于 add_stages()、parse_options()、load_dialects()
  106: make_ttir() 通过 options 间接使用
  107: make_ttgir() 通过 options 间接使用
  (109/110 通过 self.target.arch 和 self.target 间接使用)
```
