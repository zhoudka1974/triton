## 共享数据关系表

### 说明
- 「加载」= pybind11 绑定或类定义通过 import 加载
- 「实例化」= 创建类实例（局部变量，不跨阶段传递）
- 「定义」= 定义在类中作为方法
- 「注册」= 注册为延迟回调
- 「赋值」= 函数/类引用赋值给实例属性
- 「调用」= 调用函数/方法
- 「读/写」= 读写数据
- 「创建」= 首次创建该数据
- 「传递」= 通过参数传递
- 「返回」= 函数返回值

## 关键数据传递路径

### 从 101 到 112 的长线数据

```
101: import triton ────────────── 加载 driver, backends, JITFunction, compile,
                                  ASTSource, CompiledKernel, ir, passes, llvm,
                                  amd, knobs
       │
102: @triton.jit ──────────────── JITFunction.__init__() → device_caches
       │
103: kernel run ──────────────── create_binder() → target, backend, binder
       │                           binder(*args) → options, specialization
       │                           kernel_cache 查/写
       │
104: _do_compile() ──────────── ASTSource(self, ...) → self.compile(src, ...)
       │
105: compile() ───────────────── make_backend(target), ir.load_dialects()
       │                           src.make_ir() → module (mlir::ModuleOp)
       │                           backend.add_stages(stages, ...)
       │
       │    ┌────┬────┬────┬────┬────┬────┐
       │    │106 │107 │108 │111 │112 │    AMD 管道
       │    │ttir│ttg │llir│amdg│hsac│
       │    │    │    │    │cn  │o   │
       │    │    │    │    │    │    │
       │    │ module (mlir)     → str → bytes│
       │    │ metadata 贯穿全部 5 stage      │
       │    │ options: num_warps, num_stages  │
       │    │ arch: "gfx942" (AMD)            │
       │    └────┴────┴────┴────┴────┘
       │
       └─→ CompiledKernel(src, metadata_group, hash)
```

### 23~26 号共享数据的完整生命周期

```
options (HIPOptions):
  103: _pack_args() 创建
  104: 传递给 compile()
  105: backend.parse_options() 解析 → 含 arch="gfx942", num_warps 等
  106→108: 各 stage 读取 (num_warps, num_stages)
  111: 读取 options.arch ("gfx942"), options.enable_fp_fusion
  112: 读取 options.arch ("gfx942"), options.enable_asan (通过 knobs)

metadata (dict):
  105: compile() 创建
  106: make_ttir() → 可能写入
  107: make_ttgir() → 写入 tensordesc_meta
  108: make_llir() → 写入 shared, profile_scratch_size 等
  111: make_amdgcn() → 写入 name (内核函数名)
  112: make_hsaco() → 只读，不写入

src (文本字符串):
  108: make_llir() 返回 LLVM IR 文本
  111: make_amdgcn() 接收 LLVM IR → 返回 AMD GCN 汇编
  112: make_hsaco() 接收 AMD GCN 汇编 → 返回 HSACO 二进制

backend (HIPBackend 实例):
  102: create_binder() 通过 make_backend() 创建
  103: 从 device_caches 读取
  105: compile() 用于 add_stages()、parse_options()、load_dialects()
  106→108: 各 stage 通过 options 间接使用
  111→112: 通过 self.target 和 options 间接使用
```

### AMD 111~112 与其他阶段的差异

| 特性 | NVIDIA (109/110) | AMD (111/112) |
|------|-----------------|---------------|
| 汇编类型 | PTX (NVPTX target) | AMD GCN (AMDGPU target) |
| LLVM 调用 | `llvm.translate_to_asm()` | `llvm.translate_to_asm()` 同 |
| 额外信息 | 提取 `.visible .entry` 内核名 | 提取 `define amdgpu_kernel void @` 内核名 |
| 二进制工具 | `subprocess.run(ptxas)` | `amd.assemble_amdgcn()` + `amd.link_hsaco()` |
| 二进制格式 | `.cubin` | `.hsaco` |
| capability | int (89, 90) | - (使用 arch="gfx942") |
